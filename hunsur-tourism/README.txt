HOW TO ADD PHOTOS
=================

The site now checks this folder for a real photo of each place. If a photo
is present, it's shown; if not, the site quietly falls back to the existing
gold illustrated panel — nothing ever breaks.

To add a photo:
1. Save it as a .jpg
2. Name it EXACTLY like the place's id below (all lowercase, with dashes)
3. Drop it in this folder: images/places/

Example: a photo of Mysuru Palace must be named  mysuru-palace.jpg

Recommended: roughly portrait orientation (close to 4:5), at least 800px
on the short side, reasonably compressed (under ~500KB) so pages load fast.
